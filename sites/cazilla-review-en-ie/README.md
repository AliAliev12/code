# Cazilla Review EN-IE

Static HTML/CSS/vanilla JS review hub for Ireland.

- Main menu pages are prepared with long-form content and internal linking.
- Footer policy pages are expanded for legal/support context.
- All pages are set to `index, follow`.
- Canonical sitemap is generated at `sitemap.xml`.
- Apache redirects are configured in `.htaccess`.

Before production, replace `cazilla-review-en-ie.invalid` with the real domain in canonicals and sitemap.
